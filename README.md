# CrickAnalytica2023 – T20 Cricket Analytics Dashboard

## Project Overview
CrickAnalytica2023 is a cricket analytics project that explores T20 cricket data through data preprocessing, statistical analysis, and interactive Power BI visualizations.

## Tools & Technologies
- Python
- Jupyter Notebook
- Power BI
- CSV and JSON datasets

## Project Contents
- `t20_data_preprocessing.ipynb` – Notebook for data preprocessing
- `Final Dashboard of CrickAnalytica2023.pbix` – Power BI dashboard
- `WC_t20_csv_files/` – T20 cricket datasets in CSV format
- `WC_t20_json_files/` – T20 cricket datasets in JSON format
- `Project Screenshots/` – Dashboard screenshots

## Key Features
- Cricket batting and bowling performance analysis
- Player statistics and comparisons
- T20 match data exploration
- Dashboard-based data visualization

## How to Use
1. Download or clone this repository.
2. Open the notebook in Jupyter Notebook or VS Code.
3. Install the required Python libraries if needed.
4. Open the `.pbix` file using Microsoft Power BI Desktop.
